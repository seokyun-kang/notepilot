# 이 보관함의 에이전트 안내

작업을 시작하기 전에 [.notepilot/RULES.md](.notepilot/RULES.md)를 끝까지 읽는다. notepilot이 관리하는 공통 규약이며 `notepilot upgrade`가 교체하므로 고치지 않는다.

이 파일은 이 보관함만의 지침이다. 자유롭게 고쳐 쓰되 위 문단은 남겨 둔다. 공통 규약과 다른 내용이 있으면 이 파일이 우선한다. 아래 항목을 실제 사용에 맞게 채우고 해당 없는 항목은 지운다.

## 용도

무엇을 모으는 보관함인지 한두 문장으로 적는다.

## 분야

`notes/` 바로 아래 폴더가 분야다. 분야를 만들 때 이 표에 한 줄을 더한다. 하나의 노트는 주된 목적에 맞는 한 곳에만 두고 다른 분야에서는 링크로 연결한다.

## 언어와 이름

- 본문 언어:
- 파일명(제목) 규칙: 다른 노트와 구별되는 읽기 쉬운 이름을 쓴다. 정렬용 숫자나 날짜를 붙이지 않는다.
- 폴더 이름: 짧은 소문자 영어, 필요하면 kebab-case.

## 공통 규약과 다르게 쓰는 것

공통 규약보다 엄격하게 하거나 다르게 하려는 규칙, 직접 만든 폴더의 역할을 적는다. 공통 규약과 다르면 여기 적힌 내용을 따른다.

여기에 적는 것만으로 바뀌지 않는 것이 두 가지 있다.

- 폴더 이름(`notes`, `inbox`, `temp`, `templates`, `assets`)은 `notepilot rename <폴더> <새 이름>`으로 바꾼다. 이미 직접 바꿨다면 `--moved`를 붙인다.
- `README.md`, 노트의 `목차`·`근거와 참고 자료`·`관련 문서` 절 제목, 속성 일곱 개는 고정이다. 바꾸면 `notepilot check`가 오류를 낸다.

## 결정과 예외

이 보관함에서 정한 운영 결정, 보호할 자료, 날짜 보정 같은 일회성 조치를 날짜와 함께 적는다.
